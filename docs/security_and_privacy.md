# Security and Privacy

## Public-data policy

This repository accepts only data generated independently for the project or obtained from a clearly documented public source with compatible terms.

## Prohibited content

- Employer work orders, notes, labels, mappings, or identifiers
- Modified or paraphrased employer records
- Internal table, system, facility, or employee names
- Production screenshots or architecture diagrams
- Credentials, tokens, workspace URLs, or connection strings
- Proprietary business rules copied from an employer environment

## Controls

- Generated samples are reproducible from code.
- CSV data is ignored by default to prevent accidental bulk commits.
- CI will be expanded with secret scanning and notebook-output checks.
- Pull requests include a privacy confirmation.
