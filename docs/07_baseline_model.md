# 07 — Baseline Recommendation Model

## Objective

Establish an interpretable benchmark before evaluating the SLM.

## Planned approach

- TF-IDF text features
- Logistic Regression classifier
- Top-1 and Top-3 recommendations
- Grouped or time-aware split to reduce duplicate leakage
- Common-versus-rare code evaluation
- Confidence and error analysis

## Required metrics

- Top-1 accuracy
- Top-3 accuracy
- Macro and weighted F1
- Per-code support and performance
- Confused-code pairs
- Coverage at confidence thresholds

## Status

Planned for milestone v0.4 after Gold training data is reproducible.
